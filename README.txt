KRIZZIA VPN FAST - VERSION 2

WHAT THIS DOES
- Uses live-tested public nodes from PH, HK, JP, SG, TW, and US.
- Keeps only a small set so Clash refreshes quickly.
- Updates the generated clash.yaml automatically every 3 hours.
- Auto Fastest retests nodes from your own connection every 5 minutes.

UPLOAD TO GITHUB
1. Extract this ZIP.
2. Upload build.py and README.txt to the root of your existing repository.
3. Upload update-vpn.yml inside .github/workflows/.
4. Upload clash.yaml to the root too, replacing the old clash.yaml.
5. In GitHub Actions, run "Update Krizzia VPN" once if it has not run automatically.

CLASH SUBSCRIPTION
Keep using the same Raw link of clash.yaml as your subscription URL.

IMPORTANT
Free public nodes can become slow or disappear without warning. Never use them
for banking, payments, work secrets, or sensitive logins because the server
operator is a third party.
